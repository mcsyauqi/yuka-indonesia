Ringkasan

Artikel "Tunaganda Adalah" yang dijadwalkan tayang 27 Maret 2026 tidak muncul di halaman blog meskipun GitHub Actions workflow melaporkan "success". Root cause: saat fitur search & filter ditambahkan ke blog.html, ID attribute ditambahkan ke elemen blog-grid, mengubah marker dari <div class="blog-grid"> menjadi <div class="blog-grid" id="blogGrid">. Workflow masih mencari marker lama, sehingga Python string replace() gagal diam-diam tanpa error.

Root Cause Analysis

Root Cause: Blog grid marker mismatch antara workflow YAML dan blog.html setelah penambahan fitur search/filter.

Marker Sebelum (di Workflow)

marker = '<div class="blog-grid">'

Marker Sesudah (di blog.html setelah commit 568da37)

marker = '<div class="blog-grid" id="blogGrid">'

Mengapa Tidak Ada Error?

Python str.replace(marker, ...) tidak melempar exception jika string tidak ditemukan — ia hanya tidak melakukan apa-apa dan mengembalikan string asli. Akibatnya:

  • blog.html ditulis ulang tapi isinya identik (tidak berubah)
  • Git tidak mendeteksi perubahan pada blog.html
  • Workflow tetap melanjutkan ke step berikutnya (update schedule, commit, push)
  • Step "Commit and push changes" sukses karena publish-schedule.json dan sitemap.xml memang berubah
  • Email notifikasi dikirim seolah artikel berhasil dipublikasikan
